# Chapter 1: Why Event-Driven Architecture?

This chapter is conceptual. It has no runnable code.

Topics covered:

- The cost of tight coupling in distributed systems
- How events decouple producers from consumers
- Comparing request-response, messaging, and event streaming
- When event-driven architecture is the right trade-off (and when it is not)
- Introducing the CinéTrack domain used throughout the book

Start with Chapter 2 for the first hands-on Kafka examples.
